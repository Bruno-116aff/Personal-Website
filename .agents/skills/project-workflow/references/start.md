# Start a task

1. Require one exact SITE-NNN task ID.
2. Search docs/tasks/ACTIVE.md with rg and open only the linked active task.
3. Confirm the task state and dependencies.
4. Read the task's targeted files and relevant source-of-truth documents.
5. Report objective, acceptance criteria, risks and first action.
6. Implement only when the user asked for implementation.

A predecessor in COMPLETE or IMPLEMENTED_PENDING_GATE is sufficient when the task declares that dependency.
